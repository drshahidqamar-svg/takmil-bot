════════════════════════════════════════════════════════════════
TROUBLESHOOTING
════════════════════════════════════════════════
Bot not responding?
  → Check Railway logs for errors
  → Make sure you added handleVideoCommands() call in webhook

"School SCH-047 not found"?
  → SQL seed didn't run — check Railway query tab

"No active section found"?
  → section_completions table not seeded — re-run SQL

Role not switching?
  → user_roles table not seeded — re-run SQL

Codes not verifying?
  → The simplified version accepts codes as-is (coordinator does human check)
  → Full code verification requires video filename in the DAILY message
