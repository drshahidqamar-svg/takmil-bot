================================================================
WHY THIS PAGE EXISTS
================================================================

TAKMIL runs a cohort model:
  - All students in a school START at Level 1 together
  - All students MOVE to the next level together
  - No student advances alone — the whole class moves as one
  - This continues Level 1 → 2 → 3 ... → 11 → Grand Assessment
  - Completing all levels = 5 years of primary education in 12 months

The Ops team monitors Math, English, and Urdu assessment scores.
When the class shows mastery of the current level's content (SLOs),
the Ops team advances the whole school to the next level.

THIS PAGE IS WHERE THAT HAPPENS.

Before this page existed:
  ❌ Ops had to manually update SQL in DBeaver
  ❌ No record of who advanced which school
  ❌ No automatic notification to coordinators
  ❌ Easy to make mistakes

With this page:
  ✅ One button advances the whole school
  ✅ All students updated automatically
  ✅ Regional coordinator gets WhatsApp notification
  ✅ Full audit trail — who advanced, when, with notes
  ✅ Assessment scores visible before deciding

================================================================
IMPORTANT RULES FOR OPS TEAM
================================================================

1. NEVER advance a school without reviewing scores first.
   If Math/English/Urdu show — (no data), run assessments first.

2. Always add a note when advancing. This creates an audit
   trail for donors and management.

3. Grand Assessment advancement is PERMANENT. It marks all
   students as graduated. Only do this after the actual
   Grand Assessment has been conducted and passed.

4. If you advance a school by mistake, contact the tech
   team to reverse it in the database. There is no undo
   button on this page.

5. Coordinate with regional coordinators before advancing.
   They should be expecting the WhatsApp notification.


================================================================
DATABASE QUERIES FOR VERIFICATION
================================================================

See all schools and their current levels:
  SELECT name, identifier, current_level, province
  FROM schools WHERE identifier IS NOT NULL
  ORDER BY current_level DESC, province;

See full advancement history:
  SELECT school_identifier, from_level, to_level,
         student_count, advanced_by, notes, advanced_at
  FROM level_progression
  ORDER BY advanced_at DESC;

See all graduated students:
  SELECT student_name, school_identifier, graduated_at
  FROM students_register
  WHERE graduated = TRUE
  ORDER BY graduated_at DESC;

Count students per level:
  SELECT level, COUNT(*) as students
  FROM students_register
  WHERE active = TRUE
  GROUP BY level ORDER BY level;
