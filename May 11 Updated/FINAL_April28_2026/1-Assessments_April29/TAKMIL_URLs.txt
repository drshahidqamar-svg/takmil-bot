ASSESSMENT & PIN MANAGEMENT
----------------------------------------------------------------

/pin-generator      Coordinators          Login with phone + password → generate 6-digit PINs
                                          per school / level / subject. Shows only schools in
                                          coordinator's region. Levels 1-11. Math, English, Urdu.

/assess             Teachers (tablets)    Students take assessments using a PIN. Shows school,
                                          level, and subject (Math/English/Urdu) before starting.
                                          5 questions per test (production: 20). Pass = 60% (production: 80%).

/offline-portal     Teachers + Tablets    Offline-first assessment portal for classrooms with no
                                          internet. Teacher downloads PIN questions once on mobile
                                          data. Tablets connect via teacher hotspot. Results sync
                                          in batch when internet returns. See flow below.

/results            Coordinators / Ops    All assessment sessions. Click any session for
                                          student-level detail, scores, pass/fail.

/portal             Teachers              Alternative assessment portal (unified portal).


----------------------------------------------------------------
HOW OFFLINE ASSESSMENT WORKS (Teacher Hotspot Setup)
----------------------------------------------------------------

  BEFORE CLASS (Teacher - needs mobile data, takes ~3 seconds):
  1. Open /offline-portal on phone
  2. Enter PIN in "Download for Offline" card at the bottom
  3. Tap Download - saves only 20 questions for that PIN locally
  4. Done. Phone is ready.

  IN CLASS (All tablets use teacher hotspot - no SIM needed):
  5. Teacher turns on phone hotspot
  6. Each tablet connects to hotspot WiFi
  7. Each tablet opens /offline-portal in browser
  8. Student enters PIN + name - questions load instantly
  9. Student takes test - works even if hotspot drops mid-test
  10. Result saved locally on tablet automatically

  AFTER CLASS:
  11. Teacher taps "Sync Now" - all results upload in one batch

  KEY POINTS:
  - Only teacher's phone needs a SIM / mobile data
  - Tablets only need WiFi (teacher hotspot)
  - Questions downloaded once, works for all students on all tablets
  - Results never lost - saved locally until synced
  - Portal installable as an app on Android/iOS (tap Install App)
