================================================================
WHAT IS THIS CHATBOT?
================================================================

The TAKMIL WhatsApp bot lets every team member ask questions
about schools, students, attendance, and assessments in plain
English — directly on WhatsApp.

The bot knows WHO you are based on your phone number and gives
you answers relevant to YOUR role only.

  Leadership  → Big picture stats, province comparison, impact
  Ops Team    → What needs action today, missing submissions
  M&E Team    → Assessment scores, subject gaps, trends
  HR Team     → Teacher compliance, lesson completion
  Coordinators → Their region or province only


================================================================
BEFORE YOU START — SETUP
================================================================

STEP A — Register your phone number
Your Ops/Tech team must add your phone to the system.
Contact tech team with: Your Name + Phone + Role

Or admin runs in DBeaver:
  INSERT INTO bot_users (phone, name, role)
  VALUES ('+923XXXXXXXXX', 'Your Name', 'ops');

  Valid roles: leadership / ops / me / hr /
               coordinator / school_coordinator

STEP B — Get the TAKMIL Bot WhatsApp number
Contact your tech team for the Twilio WhatsApp number.
Save it in your contacts as "TAKMIL Bot"

STEP C — Send first message
WhatsApp the bot: "Hello"
You should receive a response within 10 seconds.


================================================================
HOW THE BOT WORKS
================================================================

The bot uses LIVE data from the database — no estimates,
no guesses. If data does not exist yet, it says so clearly.

Every response includes a DATA HEADER showing:
  📅 Date of data
  🏫 Total schools
  👥 Total students
  ✅ Attendance submissions today
  📝 Students tested this week

This lets you verify Claude's answer against real numbers.

If no data exists for your question, the bot replies:
  "📭 No attendance submissions found for today yet."
  NOT a made-up number.

================================================================
STEP 3 — TEST ANTI-HALLUCINATION (CRITICAL)
================================================================

This tests that the bot does NOT make up numbers.

TEST A — Ask about today when no data exists yet:
  Send: "What is the attendance rate today?"

  CORRECT response:
  "📭 No attendance submissions found for today yet."

  WRONG response (hallucination):
  "Today's attendance rate is 87%"
  ← If you see this, report it to tech team immediately

TEST B — Ask about something that doesn't exist:
  Send: "How many students graduated last year?"

  CORRECT response:
  "I don't have graduation data for last year yet."
  OR shows "0 graduated" from data header

  WRONG response (hallucination):
  "Last year 450 students graduated from TAKMIL schools"
  ← Report this immediately

TEST C — Ask a very vague question:
  Send: "How are we doing?"

  CORRECT response:
  Shows data header with real numbers then summarizes
  what IS in the database

  WRONG response:
  Generic praise about TAKMIL with no real numbers
  ← Report this

REPORT hallucinations to:
  Tech team with screenshot + exact question you sent


================================================================
STEP 4 — TEST PLAIN ENGLISH QUESTIONS
================================================================

These are free-form questions — no commands needed:

  "How many schools submitted attendance today?"
  "Which province has the highest assessment scores?"
  "Are there any schools ready to move to next level?"
  "How many students were assessed in Math this week?"
  "What is the average score in English Level 1?"
  "Which schools have not run any lessons this week?"

WHAT TO CHECK:
  ✅ Data header appears at top of every response
  ✅ Numbers in answer match numbers in data header
  ✅ No numbers appear that aren't in the data header
  ✅ Response is under 350 characters (WhatsApp friendly)
  ✅ Ends with one action item or suggestion
  ✅ Uses *bold* for key numbers


================================================================
STEP 5 — TEST ROLE ISOLATION
================================================================

Coordinators should only see their own data — not all 177 schools.

  1. Log in as a School Coordinator (Sindh province)
  2. Send: "How many schools submitted attendance today?"
  3. Answer should reference Sindh schools only — NOT 177

  If answer says "177 schools" for a province coordinator
  → Report to tech team — role filter is broken


================================================================
STEP 6 — TEST ERROR HANDLING
================================================================

Send these to test edge cases:

  "asdfghjkl" (random text)
  → Should route to normal assessment bot flow
  → Should NOT call the AI query system

  "123456" (looks like a PIN)
  → Should be treated as assessment PIN entry
  → Should NOT call AI query system

  "HELP"
  → Should show regular assessment bot help
  → NOT the coordinator command menu
