================================================================
WHY THIS PAGE EXISTS
================================================================

TAKMIL runs a cohort model:
  - All students in a school START at Level 1 together
  - All students MOVE to the next level together
  - No student advances alone — the whole class moves as one
  - This continues Level 1 → 2 → 3 ... → 11 → Grand Assessment
  - Completing all levels = 5 years of primary education in 12 months

The Ops team monitors Math, English, and Urdu assessment scores.
When the class shows mastery of the current level's content (SLOs),
the Ops team advances the whole school to the next level.

THIS PAGE IS WHERE THAT HAPPENS.

Before this page existed:
  ❌ Ops had to manually update SQL in DBeaver
  ❌ No record of who advanced which school
  ❌ No automatic notification to coordinators
  ❌ Easy to make mistakes
  ❌ Anyone could advance without seeing assessment data

With this page:
  ✅ One button advances the whole school
  ✅ Advance button is LOCKED until assessments exist
  ✅ Assessment scores visible on every card before deciding
  ✅ Traffic light system — Green/Amber/Red readiness indicator
  ✅ All students updated automatically
  ✅ Regional coordinator gets WhatsApp notification
  ✅ Full audit trail — who advanced, when, with notes

IMPORTANT RULES FOR OPS TEAM
================================================================

1. NEVER try to bypass the assessment lock. If the button
   is grey and says "Run Assessments First" — run assessments.
   The system will not let you advance without data.

2. Always add a note when advancing. This creates an audit
   trail for donors, management, and government reporting.

3. Check ALL THREE subjects before advancing:
   - Math avg should be 60%+ (production: 80%+)
   - English avg should be 60%+ (production: 80%+)
   - Urdu avg should be 60%+ (production: 80%+)

4. Grand Assessment advancement is PERMANENT. Only do this
   after the actual Grand Assessment has been conducted.

5. If you advance a school by mistake, contact the tech
   team immediately to reverse it in the database.

6. Coordinate with regional coordinators BEFORE advancing.
   They will receive an automatic WhatsApp notification.


================================================================
DATABASE QUERIES FOR VERIFICATION
================================================================

See all schools and their current levels:
  SELECT name, identifier, current_level, province
  FROM schools WHERE identifier IS NOT NULL
  ORDER BY current_level DESC, province;

See full advancement history:
  SELECT school_identifier, from_level, to_level,
         student_count, advanced_by, notes, advanced_at
  FROM level_progression
  ORDER BY advanced_at DESC;

See all graduated students:
  SELECT student_name, school_identifier, graduated_at
  FROM students_register
  WHERE graduated = TRUE
  ORDER BY graduated_at DESC;

Count students per level:
  SELECT level, COUNT(*) as students
  FROM students_register
  WHERE active = TRUE
  GROUP BY level ORDER BY level;

Check assessment readiness for all schools:
  SELECT s.name, s.identifier, s.current_level,
    ROUND(AVG(CASE WHEN ts.subject='Math'    THEN tr.score_pct END)::numeric,0) AS math_avg,
    ROUND(AVG(CASE WHEN ts.subject='English' THEN tr.score_pct END)::numeric,0) AS english_avg,
    ROUND(AVG(CASE WHEN ts.subject='Urdu'    THEN tr.score_pct END)::numeric,0) AS urdu_avg
  FROM schools s
  LEFT JOIN tablet_results tr ON tr.school_identifier = s.identifier
    AND tr.completed_at > NOW() - INTERVAL '30 days'
  LEFT JOIN tablet_sessions ts ON ts.id = tr.session_id
  WHERE s.identifier IS NOT NULL
  GROUP BY s.name, s.identifier, s.current_level
  HAVING AVG(tr.score_pct) IS NOT NULL
  ORDER BY s.province, s.name;
